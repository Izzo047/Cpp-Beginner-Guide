01 A HIGH-RETENTION METHOD

Study to understand,
not to get through it.

  1. Retrieve. Before rereading, write what you remember.
  2. Predict. Guess what the code will do, then run it.
  3. Explain. Teach the idea aloud in plain language.
  4. Return. Revisit it tomorrow, next week, and next month.
