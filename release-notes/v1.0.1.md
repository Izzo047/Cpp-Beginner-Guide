# Fieldnotes v1.0.1

## What changed

- Fixed Android edge-to-edge layout so course content respects status/navigation bars and display cutouts.
- Refined the mobile course navigation, drawer behavior, and touch targets.
- Updated the Android test build to version 1.0.1 (version code 2), allowing it to update the previous locally built debug APK when signed with the same development key.
- Kept the complete 48-lesson course available offline.

## Downloads

- **Windows:** Download `Fieldnotes-Windows.zip` and its SHA-256 checksum below.
- **Android:** A production-signed APK is published when the repository's Android signing secrets are configured. The debug APK is for testing only and is not included as a production release asset.

The Android changes passed the project build, lint, and APK-content checks. The mobile safe-area layout was also checked at narrow phone viewport sizes.
