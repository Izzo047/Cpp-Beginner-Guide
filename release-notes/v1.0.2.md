# Fieldnotes v1.0.2

## Course content

- Expanded the C++ lessons with additional explanations, examples, type/technique comparisons, and text diagrams for key flows and data structures.
- Added practical coverage for constructors, destructors, static class members, lambda captures, and `std::pair`.

## Android publishing readiness

- Targets Android 17 (API 37), above Google Play's current API 36 minimum for phone apps.
- Adds Android App Bundle (AAB) generation and validation for Google Play submissions.
- Publishes the production-signed APK and a `Fieldnotes-Android.zip` bundle with install notes and an APK SHA-256 checksum when Android signing secrets are configured.
- Keeps the directly installable debug APK for device testing.
- Adds automated checks for all 48 offline lessons, WebView security settings, target API compliance, and native-library presence.
- The package currently contains no native `.so` libraries, so no 16 KB native-library alignment is required.

## Publishing

The GitHub release workflow publishes a production-signed APK, Android ZIP, and AAB only after the repository's private Android upload-key secrets are configured. The debug APK is signed with a development key and is not a Play Store upload.
